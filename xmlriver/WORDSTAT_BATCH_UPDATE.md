# Обновление wordstat_batch.py

## Изменения

Модуль теперь **собирает частоту только для запросов, у которых её ещё нет**.

## Логика работы

### ДО изменений:
- Обрабатывались **все** запросы, даже если частотность уже была

### ПОСЛЕ изменений:
1. **Шаг 1**: Анализирует все запросы
   - Для строк (`"запрос"`) - считает, что частотности нет
   - Для объектов (`{query, frequency}`) - проверяет значение `frequency`
   - Собирает только запросы с `frequency == None` или отсутствующим
   
2. **Шаг 2**: Обрабатывает только запросы БЕЗ частотности
   - Экономит API запросы
   - Экономит время обработки

3. **Шаг 3**: Объединяет данные
   - Сохраняет существующую частотность
   - Добавляет новую частотность только для обработанных запросов

## Пример

### Входные данные:
```json
{
  "queries": [
    {"query": "запрос 1", "frequency": 100},  // Уже есть частота
    {"query": "запрос 2", "frequency": null},  // Нет частоты
    "запрос 3"                                  // Нет частоты (строка)
  ]
}
```

### Обработка:
- Обработано: **2 запроса** ("запрос 2", "запрос 3")
- Пропущено: **1 запрос** ("запрос 1")

### Выходные данные:
```json
{
  "queries": [
    {"query": "запрос 1", "frequency": 100},   // Сохранена существующая
    {"query": "запрос 2", "frequency": 50},    // Получена новая
    {"query": "запрос 3", "frequency": 25}     // Получена новая
  ]
}
```

## Статистика в логах

Теперь выводится:
```
[STEP 1] Всего запросов: 441
[STEP 1] Запросов с частотностью: 320
[STEP 1] Запросов БЕЗ частотности: 121
```

Если все запросы уже имеют частотность:
```
[STEP 1] Все запросы уже имеют частотность, обработка не требуется
```

## Преимущества

✅ Экономия API запросов (не повторяем уже полученные данные)
✅ Ускорение обработки
✅ Сохранение существующих данных
✅ Возможность дополнительной обработки (добавить только новые запросы)
